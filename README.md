# OneChat

Independent repository for the **new** OneChat prototype.

- \`backend/\`: Ktor, PostgreSQL, BCrypt, JWT, direct chats, persistent messages and WebSockets.
- \`client/\`: Kotlin Multiplatform UI and reducers using AdaptiveKT **from Maven Central**.
- \`render.yaml\`: Render Free deployment scaffold, with Neon database supplied as environment variables.

This is currently a tested API/backend and a separate KMP UI reference, **not yet a fully connected messenger**.

The old Spring/Compose prototype is removed from \`main\`. Earlier commits and other Git branches may still contain its historical files.
